# 销售对话文本提取 Skill

从销售对话文本中提取21个维度的信息，输出标准JSON格式。

## 架构说明

- **LLM（Agent）**：负责从销售对话中提取21个维度的原始信息
- **Skill**：对LLM提取结果进行后处理，包括：
  - 标准化维度格式
  - 补齐缺失维度（标记为"未提及"）
  - 生成摘要标签

## 输入

LLM提取结果的JSON，格式如下：

```json
{
  "detailed_extraction": [
    {
      "dimension": "意向车型",
      "is_match": true,
      "value": "至境E7",
      "remarks": "客户提及",
      "original_utterances": "客户：我想看看至境E7"
    }
  ]
}
```

## 输出

标准化的21维度JSON：

```json
{
  "detailed_extraction": [
    {
      "id": "1669",
      "dimension": "意向车型",
      "is_match": true,
      "value": "至境E7",
      "remarks": "客户提及",
      "original_utterances": "客户：我想看看至境E7"
    }
  ],
  "summary_tags": {
    "意向车型标签": [...],
    "竞品对比标签": [...],
    ...
  }
}
```

## 工作流集成

在 deer-flow 工作流中使用：

```json
{
  "tools": [
    {
      "name": "text-extraction",
      "description": "从销售对话中提取21维度信息",
      "input": {
        "text": "${sales_conversation_text}"
      }
    }
  ]
}
```

### 字段含义说明

| 字段 | 含义 | 示例 |
|------|------|------|
| **value** | 标准维度值 | 至境E7、10-15万、首次到店、积极 |
| **remarks** | 命中原因 | 客户明确提及意向车型为至境E7 |
| **original_utterances** | 匹配的原始对话句子 | 员工：至境E7试驾. 客户：开始。 |

### 特殊规则

1. **多选维度**（支持多个值，拆分为多个对象）：1669、1683、1687、1718、1721、1722、1725、1727、1729
2. **单选维度**（只允许一个值）：1672、1675、1680、1685、1716、1717、1719、1720、1723、1724、1728、1730
3. **维度1730（客户态度）**：仅允许返回「积极/消极/无法判定」三者之一
4. **维度1723（购车方式）**：置换≠贷款，询问置换补贴严禁映射为贷款
5. **维度1719（意向动力）**：增程≠插混，需明确提及且有购买意向才提取
