# 销售对话文本提取 Skill

从销售对话文本中提取21个维度的信息，输出标准JSON格式。

## 架构说明

- **LLM（Agent）**：负责从销售对话中提取21个维度的原始信息
- **Skill**：对LLM提取结果进行后处理，包括：
  - 标准化维度格式
  - 补齐缺失维度（标记为"未提及"）
  - 生成摘要标签

## 输入

LLM提取结果的JSON，格式如下：

```json
{
  "detailed_extraction": [
    {
      "dimension": "意向车型",
      "is_match": true,
      "value": "至境E7",
      "remarks": "客户提及",
      "original_utterances": "客户：我想看看至境E7"
    }
  ]
}
```

## 输出

标准化的21维度JSON：

```json
{
  "detailed_extraction": [
    {
      "id": "1669",
      "dimension": "意向车型",
      "is_match": true,
      "value": "至境E7",
      "remarks": "客户提及",
      "original_utterances": "客户：我想看看至境E7"
    }
  ],
  "summary_tags": {
    "意向车型标签": [...],
    "竞品对比标签": [...],
    "客户基础标签": [...],
    "核心需求标签": [...],
    "预算与购车方式标签": [...],
    "购车决策信息标签": [...],
    "服务与行动标签": [...]
  }
}
```
