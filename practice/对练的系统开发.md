# 对练的系统开发

## 新建模块：practice

## 流程简述

### 整体流程

1. 开始对练

2. 选择对练模式（意图式对练、自由应变 / 高阶挑战）

### 意图式对练流程

1. AI 生成开场白及首个问题

2. 学员回复（语音 / 文本输入）

3. 系统实时分析意图

    - 无效 / 闲聊意图：触发拉回条件

    - 有效意图：命中考核点，AI 基于上下文智能推断并推送新问题

4. 循环对话，直至触发结束条件

5. 结束流程：调用大模型生成整场对练总结与评分，生成多维对练报告（总分 / 话术能力 / 雷达图 / 学员对练结束）

### 顺序式对练流程

1. 推送剧本第一个问题

2. 学员回复（语音 / 文本输入）

3. 系统实时分析

4. 按剧本顺序推送下一个问题

5. 循环对话，判断是否为最后一个问题

    - 是：进入结束流程

    - 否：继续推送下一个问题

6. 结束流程：调用大模型生成整场对练总结与评分，生成多维对练报告（总分 / 话术能力 / 雷达图 / 学员对练结束）

## 功能模块详情

### 1、问答题库

- 维护方式：支持手工维护，也可从一篇文本中自动抽取问答，人工复核后入库。

- 分类体系：

    - 一级分类：汽车行业、银行、零售

    - 二级分类：品牌

    - 三级分类：业务类型

- 规则特点：预设或大模型提取的问答库，回答要点、得分规则均使用大模型提示词，不再逐条设置规则。

### 2、大模型剧本

- 定位：类似工牌系统方案，配置使用场景、基本参数、负面拉回策略、执行轮次等。

- 配置项：剧本名称、描述、封面、ASR 纠错词库、敏感词库、节点互动策略、结束语、对话轮次限制。

- 节点管理：配置节点主题、学员话术、机器人话术、回答要点、检核规则（替换为大模型，取消规则式说明）。

### 3、模拟角色

- 功能：配置 AI 模拟对话机器人的性别、音色、语速、语调、音量、头像、描述等参数。

- 配置项：头像、角色名称、性别、描述、发音人、语速、语调、音量、格式、样例文本。

### 4、对练课程

- 功能：设置对练基本参数（时长、分数、次数、开放时间等），分为练习和考试类型。

- 配置项：任务名称、说明、封面、关联剧本、总分、开放时间、练习模式（语音 / 文本 / 模拟电话）、难度、提示开关、允许次数、时长限制、注意事项。

### 5、对练考试

- 功能：设置考试专属参数，核心配置与课程类似，侧重考试属性。

- 配置项：考试任务名称、说明、封面、关联剧本、总分、开放时间、考试模式、难度、允许次数、时长限制、达标要求。

## H5 端功能

## 开发规则与常见问题

### 1. 字段命名规范

**问题现象**：数据保存成功但前端不回显，或前端提交数据后端无法识别

**原因分析**：
- 前端 `Scene` 接口使用驼峰命名（如 `scoringRules`）
- 后端数据库使用下划线命名（如 `scoring_rules`）

**解决规则**：
- **前端**：使用驼峰命名（camelCase）
- **后端模型（Pydantic）**：字段名使用下划线，通过 `alias` 参数映射前端驼峰命名
- **API 返回**：转换为驼峰命名，与前端保持一致

**关键文件**：
- 前端类型定义：`practice/src/types/index.ts`
- 后端路由：`backend/app/gateway/routers/roleplay.py`
- 后端模型：`backend/packages/harness/deerflow/roleplay/models.py`

---

### 2. API 数据传递规则

**问题现象**：前端提交的字段后端接收不到

**原因分析**：
- 路由层使用 `by_alias=True` 导致字段名转换错误
- Pydantic 的 `alias` 参数已处理命名转换，无需额外转换

**解决规则**：
- 创建场景：`scene.dict()` - 直接传递，不使用 `by_alias=True`
- 更新场景：`scene.dict(exclude_none=True)` - 排除空值，不使用 `by_alias=True`

**关键代码**（`roleplay.py`）：
```python
# 正确
await SceneService.create_scene(scene.dict())

# 错误（已修复）
await SceneService.create_scene(scene.dict(by_alias=True))
```

---

### 3. 数据库字段同步

**问题现象**：数据库查询报错 `Unknown column`

**原因分析**：
- 模型中新增字段未同步到数据库表

**解决规则**：
- 修改模型后必须执行数据库迁移
- 使用 ALTER TABLE 添加新字段
- 所有字段必须添加中文注释

**关键文件**：
- 数据库迁移脚本：`backend/scripts/migrate_roleplay_fields.sql`
- 模型定义：`backend/packages/harness/deerflow/roleplay/models.py`

---

### 4. 表单验证规则

**问题现象**：保存功能不生效，无任何提示

**原因分析**：
- 必填字段未验证，用户可能提交空表单
- 缺少必填字段视觉标识

**解决规则**：
- 必填字段添加红色 `*` 号标识
- 保存前进行表单验证
- 验证失败显示明确错误提示

**关键字段**：
| 字段名 | 必填条件 | 提示信息 |
|--------|----------|----------|
| 场景名称 | 始终必填 | 请输入场景名称 |
| 知识库内容 | 自由式模式 | 自由式练习模式需要填写知识库内容 |
| 评分规则 | 自由式模式 | 自由式练习模式需要填写评分规则 |

**关键文件**：`practice/src/pages/ScenePage.tsx`

---

### 5. 模型与数据库映射

**问题现象**：数据库操作报错字段不匹配

**原因分析**：
- 模型表名与实际数据库表名不一致
- 模型字段名与数据库字段名不一致

**解决规则**：
- 模型表名必须为 `pract_scene_set`
