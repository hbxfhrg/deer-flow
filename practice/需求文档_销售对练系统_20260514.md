# 销售对练系统 - 需求文档

## 1. 项目概述

### 1.1 项目名称
DeerFlow 销售对练系统

### 1.2 项目目标
构建一个AI驱动的销售技能训练平台，通过模拟真实销售场景，帮助用户提升沟通技巧和销售能力。

### 1.3 项目背景
随着市场竞争加剧，企业对销售人员的能力要求不断提高。传统培训方式成本高、效率低，难以满足大规模培训需求。本系统利用AI技术，提供沉浸式、个性化的销售训练体验。

## 3. 非功能需求

### 3.1 性能要求
- 页面响应时间 < 200ms
- API响应时间 < 500ms
- 支持1000+并发用户

### 3.2 可用性要求
- 系统可用性 ≥ 99.5%
- 数据备份频率：每日增量备份，每周全量备份

### 3.3 安全性要求
- 数据传输采用HTTPS加密
- 用户数据隔离存储
- 定期安全审计和漏洞扫描

### 3.4 兼容性要求
- 支持主流浏览器：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- 移动端适配：响应式设计，支持iOS和Android

## 6. 业务流程

### 6.1 练习流程
1. 用户进入场景选择页
2. 选择或搜索目标场景
3. 点击开始练习
4. 进入对练界面，系统开始计时
5. 用户与AI进行多轮对话
6. 每轮结束后系统自动评估
7. 练习完成后展示评估报告

### 6.2 评估流程
1. 对话结束后触发评估
2. 评分规则引擎计算各维度得分
3. 生成综合评分和评语
4. 评估结果持久化存储
5. 返回评估报告给前端
